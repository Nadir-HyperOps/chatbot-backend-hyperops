# chatbot-backend-hyperops
Backend chatbot IA HyperOps (qualification lead + validation sécurisée)

## Contribution

Travail sur `main` par défaut, avec vérification, commit cohérent et push vérifié. Les branches temporaires et Pull Requests sont utilisées lorsqu'une isolation ou une review le justifie. Voir les [instructions de contribution](AGENTS.md).

Le dépôt est public. Les secrets et données réelles restent hors Git. Vérifier l'intégration de déploiement avant de pousser une évolution du service.
